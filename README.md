# 📚 Library Management System
A desktop application built with Python to manage a library efficiently.  
The app allows managing books, members, and borrowing operations through a simple and user-friendly interface.
---
## 🚀 Features
- 📖 Add, update, delete, and search books  
- 👤 Manage members (add, edit, delete)  
- 🔄 Borrow and return books  
- ✅ Check book availability before borrowing  
- 📅 Automatic loan dates (borrow & return)  
- 🔍 Search system for books and members  
---
## 🛠️ Technologies Used
- Python  
- Tkinter (GUI)  
- SQLite (Database)
